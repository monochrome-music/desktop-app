# Monochrome Desktop

A desktop app for Monochrome, obviously.

## Installation

Check the download section on the Monochrome website for the installer. Alternatively, check the releases tab in this Github repository and find the installer for your operating system. 

## Usage

Used like how Monochrome would be used normally. Currently the only added features are Discord RPC which is turned on by default and can be enabled or disabled by right clicking the icon in your tray. More features are to come very soon.
